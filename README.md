# Python Tic-Tac-Toe

A two-player Tic-Tac-Toe game played in the terminal.

## Features

- Players X and O take turns entering a board position (0–8)
- Prints an ASCII board after each move
- Detects a win or a draw

## Tech stack

Python (no dependencies)

## Running

```bash
python main.py
```
